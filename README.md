# usb-bouncer

macOS tool that vets unknown USB devices for BadUSB red flags and keystroke injection.

## Development

This is a solo repo. Because GitHub blocks self-approval, a required-approval rule can never be satisfied on a solo project. I removed the approval requirement and kept `test` check, strict mode, no force-push, no deletion, PRs still required. Admin-override would technically satisfy the rule, but routinely doing the admin override is a bad habit — it should rather be removed. Tradeoff: no requirement of independent review, accepted knowingly.
